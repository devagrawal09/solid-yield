A block component is called, never used as a tag (D-062, D-065, D-066, D-067). JSX is for DOM elements and foreign (plain-Solid) components only. A `$component`, a `lazy` component, or one of the library's flow controls and boundaries (`For`, `Show`, `Switch`, `Match`, `Repeat`, `Loading`, `Errored`) is written `{yield* Card({ todo })}`, so its pending and failures reach the view through `yield*`. A tag's type is always `JSX.Element`, so a tag dropped them.

- **Tags are a type error.** The JSX namespace's `ElementType` is now `TagType`, which is exported: a string, or a function whose type does not carry the component brand. `<Card todo={t} />` fails to type-check, while `<div>`, `<Router>`, `<Portal>`, a context provider, and other foreign components still type-check. The `jsx.d.ts` generator emits it.
- **Props are a source, a hole, or a settled value (D-065).** Every block component prop, not only a flow control's (D-038), now accepts a zero-arity `function*` hole as well as a value or a source. The child reads the hole with `yield*` as it reads a source, and the read runs in the child's reading computation, as a tag's getter did: `Card({ total: function* () { return (yield* n) * 2; } })`. In the props type, `HoleProp<T> = () => Generator<any, T, any>` joins each prop's union.
- **Children are a generator (D-066).** `children: function* () { return <…/>; }` is a lazy view. It is built where, and each time, the control shows its content, untracked, and its holes are its own. A list's or a branch's children are a row, `function* (item, index) { … }`. A flow control's `fallback` may also be written as a lazy view, `fallback: function* () { return <>{yield* Checkout()}</>; }`, which sets the component up only when the fallback is shown, as `fallback={<Checkout />}` did. A plain JSX `fallback` is still accepted.
- **Flow control signatures.** These follow the call form: `For` (a row, or an `(item, index) => …` callback in `h`), `Show`, `Match`, `Repeat` (a lazy view, a row, or content), `Switch` (its `children` a lazy view of `Match` calls), `Loading`, and `Errored`. Each returns a `View` colored by what it holds: its sources, its holes, its rows' views, and its lazy views. `Loading` clears its children's pending, and `Errored` (with or without `catch`) clears the failures it handles. Hole and row types no longer recurse into JSX elements (`OpsOfHole` treats an `Element` as settled), which fixes "excessively deep" errors and `any` colors on recursive rows.

The twins and the package tests are migrated: 104 block component tags in the twins become calls (11 foreign component tags remain), and so do the package tests' tags, children, and in-prop reads.
