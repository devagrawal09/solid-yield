# O1–O52: proof and evidence map

This map audits the wording in [calculus §5](../calculus.md#5-proof-obligations-traceability-matrix),
not just whether its examples pass. The source revision is `1da4d82`.

- **M — mechanized model lemma.** Lean proves the stated algebra or routing rule
  in [YieldProofs.lean](lean/YieldProofs.lean). This is **not** a proof that all
  TypeScript values implement that model. P-STATE's interface/owner invariant
  is needed to apply it to JavaScript.
- **P — paper proof.** [paper.md](paper.md) gives the rule and case argument,
  relative to the explicitly listed Solid and environment assumptions. This
  does not claim a checked TypeScript-to-model refinement.
- **U — unprovable as stated.** The original wording has a counterexample,
  an obsolete premise, or a behavioral claim not implied by its assumptions.
  The row identifies which. A conditional or weaker lemma is still supplied.

For each row the final column names existing evidence, not an extra premise
that passing tests somehow prove. Paths below are relative to
`packages/yield/test/`: `jsx` = `jsx.type-tests.tsx`, `nojsx-t` =
`nojsx.type-tests.ts`, `raise-t` = `raise.type-tests.tsx`, `ctx-t` =
`context.type-tests.tsx`, `root-t` = `root.type-tests.tsx`, `rt` =
`runtime.spec.tsx`, `obl` = `obligations.spec.tsx`, `raise` = `raise.spec.tsx`,
`nojsx` = `nojsx.spec.ts`, `ssr` = `server/ssr.spec.tsx`, and `thunk` =
`render-thunk.spec.tsx`. Stable scenario descriptions are preferred to line
numbers. New witnesses are in [probes](probes/counterexamples.tsx) and
[findings](findings.md).

## Status totals and theorem verdict

- **M (12):** O1, O2, O3, O4, O5, O12, O24, O25, O28, O31, O35, O49.
- **P (26):** O6, O8, O9, O10, O13, O15, O16, O17, O18, O19, O22, O23,
  O29, O30, O32, O37, O38, O40, O41, O42, O44, O45, O48, O50, O51, O52.
- **U (14):** O7, O11, O14, O20, O21, O26, O27, O33, O34, O36, O39, O43,
  O46, O47.

These are mutually exclusive primary classifications: several P/U rows also
have checked model sublemmas. No M row claims a fully verified library.
O14/O21/O36 are marked U partly for missing premises, not a claim that their
tested normal cases fail. The broader all-programs theorem fails independently
of those assumption gaps: F02/F03 hide failures, F04/F05/F07/F13 hide context
requirements, F06 crosses an unchecked foreign environment, and F08/F09 remove
failures that runtime still delivers. F01 independently refutes the converse.

With P-STATE's independent invariant, the stated Solid contracts, and deferred
boundary construction, `execution_root` proves the requested safety result
for the abstract model: no unhandled pending or missing context, and no failure
at a position whose failure set is empty. Escaping failures allowed by the root
are rethrown by the runtime contract. Claiming that TypeScript acceptance alone
supplies these premises would repeat the original gap.
