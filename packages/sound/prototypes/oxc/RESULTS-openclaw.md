## Precision and the remaining extra

OpenClaw improves from 9 hits / 8 misses / 16 extras to 17 / 0 / 0. All 18 clean
controls have no error/warning diagnostics. Its 16 extras were removed by:

- Modeling key-function and position-mode row accessors and preserving their
  element shapes: ten spurious pending/failure errors removed.
- Supporting ref capture and read scopes: four blanket partial warnings and
  one incorrect pending-handler warning removed.
- Reporting an escaping untrack failure at the call: one misplaced extra
  becomes the required hit. A real local catch still handles it.

Effect apply/helper reads and explicit undefined context defaults now produce
required findings. Lazy unused props, fulfilled outcome observation, project
methods and separate promise branches already retained the right facts.

The sole remaining scored extra is STRICT_READ_UNTRACKED at
cases/ref-event-reads.tsx:1:117. Its ref takes an untracked signal snapshot, even
though it also writes a signal. The frozen old note says ref reads are fine;
D-131 supersedes that note. The runtime probe shows one callback run, a nullish
observer, and a snapshot still equal to 1 after JSX updates to 4. Suppressing
this read would be unsound under the new rule, not a precision improvement.
The required partial warning remains for deferred ref write ownership; no
setup-write error is invented. See DISPUTES.md and ref-runtime.test.jsx.

## Validation, changes and limits

Run in order after the final source edit:

1. node harness/run.mjs — exits 0; C has zero soundness failures/missed mutants.
2. node harness/vite-measure.mjs oxc --runs 5 — exits 0; policy behaves as above.
3. pnpm test — 218 passed, one disputed old-case precision assertion failed.

The two independence tests pass: the source scan rejects TypeScript imports,
and a child process blocks TypeScript resolution while loading C and its Vite
wrapper and checking all 143 fixtures. Thirteen new static regression tests
and one new runtime probe pass. The frozen 11 runtime probes also pass.
Only C's OpenClaw score pins were tightened; A/B/null pins are byte-equivalent
as parsed data. Fixtures, harness, shared sources/rules, other prototypes,
frozen tests and COMPARISON.md were not changed. results/latest.* are not staged.

LOC versus the starting point, excluding docs and generated measurement/pin JSON:
checker +67 net (analyze.mjs +93/-26; graph.mjs +1/-1), measurement script +5
(+7/-2), regression tests +201 (161 static, 40 runtime). Total code delta +273.

No known missed frozen in-subset requirement remains. Broader limits are still
annotation-only declaration coverage, no general type inference, coarse heap
correlation, loop/recursion widening, incomplete platform contracts, and full
invocation-graph rebuilding on updates. Unknown key modes warn and widen;
callable key modes retain their failures. Ref ownership/cleanup/primitive
creation and the other FUTURE.md topics remain deferred. The one stale original
ref expectation is the only dispute; it prevents claiming a fully passing suite.
