`$` and `$scope` are removed from `@solidjs/blocks`, with the `Block` type, its `BLOCK` brand and the `BODY` / `ROW_MARK` marks: a row and a no-JSX hole are bare `function*`s, and a derivation several holes read is a `yield* $memo(…)` (D-013). A row's body is now a setup in the same sense as a `$component`'s (D-030). It runs once per row (per item of a `For`, per shown branch of a `Show` / `Match`, per index of a `Repeat`, per error of an `Errored` fallback), untracked, with the render arguments as reads. It creates state, and a `yield* $memo` there belongs to the row, created once per item and disposed with it. It returns the row's view generator. A row that returns its markup directly is now the dev error `[ROW_VIEW]`, as a setup that returns no view is `[COMPONENT_VIEW]` (the types already required the view). In the no-JSX flavor a bare zero-arity `function*` is a hole wherever `h` / `html` take one, and now also as a flow control's source prop in the direct-call form (`Show({ when: function* () { … }, children })`, typed with the hole's pending and failures). In JSX a bare `function*` is not a child or an attribute value: the transform hands it to the web renderer as it is, and the renderer does not drive generators, so the JSX hole stays the `yield*`. A source that used to be a module-level `$` block (a context default) is created by the setup that asks for it.

`@solidjs/eslint-plugin-blocks`: new `no-dollar-block` (in `recommended`) reports every use of `$` / `$scope` imported from `@solidjs/blocks` (or unbound) and its import, and fixes what has one equivalent form. `$(function* (item) …)` and `$scope(fn)` become the bare function. A zero-arity `$(function* …)` in a no-JSX hole (an `h` child or attribute value, an `html` template value, a flow control's `when` / `each` / `count` / `on`) becomes the bare `function*`. One bound to a `const` in a setup or a row's setup becomes `yield* $memo(…)`, and the import drops `$` / `$scope` and adds `$memo`. A module-level `$` source or a `$` block as a JSX child is reported without a fix. The rule stays after the removal to report any remaining use. The twins were migrated with it: 32 sites in block code (28 fixed, the rendering twin's router and the room twin's identity default by hand) and 13 in the package's tests.
